HOW TO USE
三種用法，挑最適合你的
有 AI 代理人最推薦 · 整套自動跑

① 裝成 Skill，交給你的 AI 代理人（Claude Code / Codex / Cursor）

  1. 按上面「下載這個工具」解壓縮，把裡面的 skill/evidence-report 整個資料夾放進你的 skill 資料夾（Claude Code 是 .claude/skills/）。
  2. 把截圖放進一個資料夾，跟你的 AI 說這句話（複製整段）：
    這是小腸老師給我的蒐證報告 Skill，請照 skill/evidence-report/SKILL.md 幫我把這個資料夾的截圖整理成一份能送件的報告。
  3. 它會照時間排好、標可信度、自動在截圖上畫紅框、掃出不該露的個資，最後產出 PDF。
💡 Mac 和 Windows 都能整套跑完：畫紅框、遮個資掃描用電腦內建的文字辨識（Mac 第一次會先編譯一個小工具；Windows 若提示沒裝中文辨識，照提示補裝一次，免費），PDF 用 Chrome 或 Edge 產（Windows 內建 Edge）。你的 AI 會照 Skill 說明自己處理。用 Windows 的看下面那段。
用 Windows 的看這裡 · 雲端 Windows 實測過

Windows 第一次跑 Skill，照這幾步

  1. 還沒有 Python（打 python 跳出 Microsoft Store 就是沒有）：到 python.org 下載安裝，安裝第一頁一定要勾「Add python.exe to PATH」，裝完把 PowerShell 關掉重開。
  2. 第一次畫紅框跳出「沒裝中文文字辨識」是正常的，照提示補裝一次（免費）。
  1. 在開始鍵按右鍵選 「終端機（系統管理員）」，貼上提示裡那行補裝。會跑 10 到 20 分鐘，畫面不動是正常的，別關視窗；裝完同一個視窗就能用，不用重開機。
  1. 裝好再跑一次，重點句就自動畫上紅框。
  1. 程式說「這幾句沒框到」時，打開那張圖確認，必要時手動補框（Windows 辨識偶爾會把相似字認錯）。
  1. 產好的 PDF 用內建的 Edge 打開看一眼：中文正常、版面沒切。

這幾張是 2026-11-10 在雲端 Windows 照上面步驟真的跑出來的截圖。測試機是英文介面，中文 Windows 步驟一樣，只是按鈕與選單是中文。

什麼都不想裝 · 打開就能用

② 直接用網頁版

  1. 手機或電腦打開 https://knowledgegut.com/evidence，不用註冊、不用下載。
  2. 照頁面上的 ①②③ 步驟走：丟截圖講經過 → 一鍵複製指令貼給你的 AI → 把 AI 的回覆貼回來。
  3. 報告出來後逐句核對，按「印出／存成 PDF」就完成 🎉
想離線用網頁版

③ 下載網頁版到自己的電腦

  1. 解壓縮後用瀏覽器打開 index.html，斷網也能用。
  2. 草稿只存在這台電腦，按「清空」就刪掉。
💡 這是整理工具，不是法律意見。報告是「送件用」不是「公審用」：交給官方、平台、律師或對方本人就好，不要公開張貼。
